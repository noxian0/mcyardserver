# Changelog

## 0.1.1 — 2026-10-30

- Fixed garbled punctuation in command results, including the Stop acknowledgement.
- Existing command-result history displays correctly without rewriting saved records.
- Fixed the separators in player locations and live-player status labels.

## 0.1.0 — 2026-10-30

- First public release under the MCyard Server Custom License by noxian0.
- Source publication excludes maintainer tests, temporary output and private server data.

- More visible panorama motion, actual Overworld day/night lighting and weather shading.
- Saved Animations switch with immediate cross-window updates and idle rendering when hidden.
- Shared local banners for new servers and an original forest fallback without a Minecraft install.
- Footer credits: GitHub: noxian0 | Discord: noxian_.
- Inventory transfers with stack-revision checks, capacity validation and optional chat messages.
- Player Kill and Freeze/Unfreeze controls with acknowledged actions and local history.

- Per-user Windows setup EXE with Desktop shortcuts and managed Java installation.
- On-demand Java installation in the creation wizard, without system PATH changes.
- Animated navigation, page transitions and button feedback; removed the redundant sidebar status.
- Initial Windows desktop release with a multi-server library and creation wizard.
- Vanilla, Fabric and Forge creation with publisher version catalogs and isolated folders.
- Editable RAM and reversible mod enable/disable controls.
- Existing Vanilla/Fabric/Forge server import without moving worlds or replacing settings.
- Compatible legacy bridge protection and preservation of imported heap/timezone options.
- Tested Fabric 26.3 preset with Java validation and explicit Minecraft EULA acceptance.
- Local player management, inventory/location inspection, history and console.
- World-rule switches and searchable server settings.
- Verified offline snapshots and live world backups with a shared 50 GB cap per server.
- Original icons, optional local backgrounds, transitions and reduced-motion support.
- Source/build documentation and a Windows build workflow for GitHub.
